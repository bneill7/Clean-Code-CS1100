# Clean-Code-CS1100
A set of exercises in writing clean code. Exercises are found in the ArtStoreUtil.java file. 

# For each excercise...
there will be a JavaDocs comment explaining the (intended) functionality of the relevant part. Under that will be some questions to prompt fixes that will clean up the implementation. Finally, each exercise has a difficulty assigned. Difficulty is determine by necessary Java prereq knowledge, how elusive the solution is, and how long it is projected to take. I would recommend having a copy of the original so you can reference it as you refactor.
